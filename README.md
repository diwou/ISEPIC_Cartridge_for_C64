# ISEPIC-Cartridge für den Commodore C64

Dies ist eine Nachbildung der bekannten ISEPIC-Cartridge, die 1985 auf den Markt kam.

![](https://https://codeberg.org/diwou/ISEPIC_Cartridge_for_C64/raw/branch/main/Images/Z80-Card_design_pcb.jpg)
